# 3. Two vendor conventions found during the gate and recorded rather than smoothed over
#   a) timestamps arrive at millisecond precision in New York time while landed partitions hold
#      microseconds. Both are cast to one explicit unit before comparison; after the cast the
#      instants must be identical. This is a unit alignment, not a tolerance.
#   b) a minute with no trade returns NaN open/high/low/close with volume 0. That is a real vendor
#      state, distinct from a missing bar and from a halt. The comparison treats absence on both
#      sides as a match and absence on one side as a discrepancy, and the three are never merged.
#      The first comparison did not handle this and reported 473 false discrepancies on one
#      thinly traded symbol while the maximum price delta was 0.0; the gate caught it.

# RESUME PROCEDURE
# Every stage is resumable and idempotent. A partition is skipped only when it already exists and
# reads back as valid parquet; writes are atomic through a temporary file and a replace, so an
# interrupted run cannot leave a half-written partition behind. Vendor errors are appended to
# data/holdout2024/work/vendor_errors_<stage>.jsonl and never written into a market-data partition.
#
# To resume after any interruption, re-run the same commands in order; completed work is skipped:
#   python scripts/cg_arrow013_acquire.py eod  --workers 8
#   python scripts/cg_arrow013_eligibility.py  --workers 8
#   python scripts/cg_arrow013_acquire.py bars --workers 8
#   python scripts/cg_arrow013_certify.py      --workers 8 --sample 400
#   python scripts/cg_arrow013_report.py
#
# Preferred overnight resume for the minute layer, which survives session expiry:
#   python scripts/cg_arrow013_supervise.py --attempts 60 --workers 8
#
# To resume only specific months of the minute layer:
#   python scripts/cg_arrow013_acquire.py bars --workers 8 --months 2025-04,2025-05,2025-06
#
# Last completed minute chunk is recorded in data/holdout2024/work/bars_progress.json.
